## 캐릭터 원화 생성

**미니맥스 스프라이트 시트 배경 제거**: 새 동작 생성에서 ‘투명 PNG 시트도 만들기 → AI’를 기본 선택합니다. AI가 선택된 프레임마다 배경을 제거하고 원본 영상·시트와 별도 투명 시트를 저장합니다. 기존 결과는 갤러리 상세의 **도구 → 시트 다시 추출 → AI 배경 제거**로 다시 뽑을 수 있습니다. 단색 제거도 선택 가능하며, 영상 자체는 투명해지지 않습니다. [배경 제거 인계](DOCS/IMAGE_BACKGROUND.md).

**영상 기반 걷기·달리기**: 스프라이트 시트 도구의 **세팅 모음**에서 걷기/달리기 영상 테스트 세팅을 불러옵니다. 팔·몸통·코트가 이어서 움직이는 영상을 생성하고, 결과의 **반복 구간 고르기**에서 원본 영상을 프레임 단위로 살펴 시작·끝을 지정하고, 마지막→처음 비교와 구간 반복 재생 후 원하는 장수로 시트를 만듭니다. 잘라낸 시트·ZIP은 새 버전으로 저장하며 이전 버전을 복원할 수 있습니다. [프레임 편집·루프 정리](DOCS/FRAME_EDITOR.md). 프레임별 포즈 생성 실험은 종료했으며 [실험 기록](DOCS/POSE_MOTION.md)만 보존합니다.

**캐릭터 작업실**: 왼쪽 메뉴에서 원화·그림체 설정·방향·동작·리깅 결과를 캐릭터별로 연결하고, 생성 화면으로 대표 원화와 설정을 가져올 수 있습니다. [사용법·인계](DOCS/CHARACTER_WORKSPACE.md).

**스프라이트 프레임 편집**: 결과 상세에서 프레임을 재생·고정하고, 칠한 영역만 AI 수정 후보로 만든 뒤 비교·적용합니다. PNG·시트·FPS JSON ZIP과 이전 버전 복원을 지원합니다. [사용법·인계](DOCS/FRAME_EDITOR.md).

**눈·입·장비 재생성**: 결과/내부 공유의 레이어 편집기에서 감긴 눈·입 차분 또는 object만 다시 생성하고 비교 후 교체할 수 있습니다. 저장하면 새 버전으로 갤러리·내부 공유에 반영됩니다. [재생성 사용법·인계](DOCS/LIVE2D_REGENERATION.md).

**리깅 전 눈·입 마스킹**은 B 브러시 / E 선택 영역 지우개 / H·Space 화면 이동, Ctrl+Z·다시 실행, Ctrl+휠 확대, 마스크 투명도와 표시 전환을 지원합니다. [마스킹 조작·인계](DOCS/LIVE2D_MASKING.md).

**Live2D 화질 개선**: 리깅 스튜디오 상단 **화질 개선**에서 AI 선·채색 개선 또는 일반 확대를 선택합니다. 2배/4배 레이어·표정·PSD·Unity V2를 새 버전으로 적용하며 갤러리·내부 공유에도 반영됩니다. [레이어 화질 개선 안내](DOCS/LIVE2D_UPSCALE.md).

**이미지 스튜디오**는 새 원화 생성 / 원화를 전투 스프라이트로 변환 / 그림 일부 수정 / 4방향 시트 제작으로 나뉩니다. 작업을 고르면 추천 설정을 준비하고, 그림체는 우측 패널에서 예시를 보고 고릅니다. 원화 변환은 방향·관절 자세와 여러 후보 비교를 지원하며 결과를 부분 수정으로 이어갈 수 있습니다. 생성 엔진과 개별 강도는 고급 설정에 있습니다. [스프라이트 변환 인계 문서](DOCS/SPRITE_STUDIO_CONVERSION.md), [이미지 스튜디오 UI·운영 인계](DOCS/IMAGE_STUDIO.md)를 참고하세요.

RPG 원화는 **Flanime · RPG 원본 고해상도 + Epic Seven LoRA**로 1024×1536 / 40 steps 원본 생성을 지원합니다. 확대·전체 재생성은 기본으로 적용하지 않습니다. Hires보다 이 원본 생성 경로를 우선 시험합니다.

Flanime의 선택형 **얼굴 보정**은 원본 크기를 유지하고 얼굴만 약하게 보정합니다. 결과에서 보정 전 원본과 비교할 수 있습니다.

RPG 전투 원화용 **Illustrious XL 1.0** 경로와 Counter Side / Epic Seven 스프라이트 LoRA 카드를 추가했습니다. 캐릭터 태그와 화풍을 별도로 지정하며 896×1152를 지원합니다. 검증 대기·무결성 실패 파일은 비활성화합니다. 설치·실생성 상태와 주의점은 [LoRA 인계 문서](DOCS/IMAGE_STYLES.md)를 참고하세요.

Illustrious / Animagine 새로 생성에는 선택형 **얼굴 보정**도 제공합니다. 2배 캔버스에서 얼굴만 다시 그리며 결과의 **보정 전 보기**로 단순 확대본과 비교할 수 있습니다. 캐릭터 인상이 바뀔 수 있어 기본값은 꺼져 있습니다.

**고해상도 2차 생성**은 2배 확대 후 전신을 낮은 변형 강도로 다시 그립니다. 얼굴 보정과 함께 선택할 수 있고 **전체 보정 전 보기**로 비교합니다. 의상·무기가 달라질 수 있어 선택형 실험 기능으로 제공합니다.

스프라이트 생성기에는 기존 H3와 별도로 FastH3 8-step 워크플로우 선택 항목을 추가했습니다. 실험 프로필로 선택할 수 있으며, 검증 기록과 주의점은 [FastH3 인계 문서](DOCS/FASTH3_SPRITE_WORKFLOW.md)를 참고하세요.

LoRA 라이브러리·그림체 프리셋·프롬프트 템플릿을 별도 탭으로 제공합니다. 기존 추천과 Soya용 36종을 합쳐 일반 그림체 프리셋 69종을 제공하며, 셀 채색·선화·게임 일러스트·수채 계열의 실제 생성 예시와 적용 설정을 보고 선택할 수 있습니다. 9개 단위 페이지와 검색을 지원합니다. [그림체 프리셋 인계 문서](DOCS/IMAGE_LOOKS.md)를 참고하세요.

원화·스프라이트 스튜디오 첫 진입에서 **에셋 유형 → 시작 방법 → 방향 수·기준 방향**을 선택합니다. 탑다운·측면 전투·아이소메트릭을 구분하고, 현재 생성은 한 방향입니다. 4/8방향은 제작 계획으로 저장합니다. 별도 **RPG 4방향 시트** 도트풍·SD풍 옵션에서는 3×4 시트 초안을 생성하며, 선택형 칸별 배경 제거를 지원합니다. 구현과 전용 LoRA 조사 결과는 [에셋 유형·다방향 인계](DOCS/ASSET_TYPES_AND_DIRECTIONS.md)를 참고하세요.

로그인 후 **이미지 스튜디오 → 새 이미지 만들기**의 기본 생성 조합은 **Soya · Anima → Flanime**입니다. Anima/Kieed 생성 후 2배 확대·Flanime 재처리를 수행하고, 기본 1536×1536 PNG와 선택형 투명 배경을 제공합니다. Detailed anime LoRA는 원본과 동일성 미확인 후보 버전이며 장비·의상이 달라질 수 있습니다. 기존 Anima Turbo 1.1 / Animagine XL 4.0도 선택할 수 있고, 참고 이미지 변형·마스크 부분 수정은 해당 방식으로 전환됩니다. 결과는 팀 갤러리에 저장되며 스프라이트·Live2D 제작 도구로 바로 보낼 수 있습니다. 모델 설치, 라이선스, API와 유지보수는 [캐릭터 원화 인계 문서](DOCS/IMAGE_STUDIO.md)를 참고하세요.

## 2D 리깅·Live2D풍 도구

**로컬 픽셀 아트**: 이미지 스튜디오의 픽셀 아트 작업에서 SDXL + Pixel Art XL 전용 조합으로 64·96·128px 정지 도트 PNG를 만듭니다. 색상 제한·참고 이미지 변형·8배 미리보기를 지원합니다. 모델 설치와 실제 생성 품질 검증은 별도이며 준비 상태를 확인하세요. [사용법·설치·인계](DOCS/PIXEL_ART.md).

이미지·스프라이트·리깅 생성 화면은 **왼쪽 설정 / 오른쪽 전체 작업 화면**을 사용합니다. 설정은 독립 스크롤하고 생성 버튼은 하단에 남습니다. 이미지 후보 목록·크게 보기와 모바일 설정/작업 전환을 지원합니다. [공통 작업공간 UI 인계](DOCS/CREATION_WORKSPACE.md).

레이어 수정 화면 상단 **Live2D 미리보기**를 누르면 편집 화면 옆에서 바로 움직임을 확인합니다. 저장 전 지우개·복원·그리기·레이어 표시와 순서 변경도 자동 반영하며, 깜박임·입 움직임·대기 동작과 일시정지를 조절할 수 있습니다. 내부 공유 편집기에서도 지원합니다. [미리보기 구현·인계](DOCS/LIVE2D_LIVE_PREVIEW.md).

**포즈 테스트**에 손·발 IK와 타임라인이 있습니다. 자세를 키프레임으로 기록하고 보간·반복 재생한 뒤 작업 버전과 Unity V2 클립으로 저장합니다. [IK·타임라인 가이드](DOCS/LIVE2D_TIMELINE.md)를 참고하세요. Unity 클립은 임포터 0.4.0부터 지원합니다.

레이어 편집기의 **본 위치·연결 / 포즈 테스트**에서 전신 본을 시각화하고 관절·파츠 연결을 고칠 수 있습니다. 머리카락·코트·토시 등에 유연 조작점을 추가하고 실제 메시 변형을 시험합니다. 저장한 본과 웨이트는 Unity V2에 연결됩니다. 사용법과 제한은 [웹 본 편집 가이드](DOCS/LIVE2D_BONE_EDITOR.md)를 참고하세요.

레이어 편집기의 **표정 차분**에서 눈·입·눈썹을 직접 그리거나 투명 PNG로 가져올 수 있습니다. **P** 색상 브러시와 **E** 지우개로 편집한 뒤 기존 움직임 슬롯에 적용하고 저장합니다. 차분은 별도로 보관되며 PSD·Unity ZIP에 포함됩니다. 사용법과 구현 인계는 [표정 차분 가이드](DOCS/LIVE2D_EXPRESSIONS.md)를 참고하세요.

로그인 후 **2D 리깅** 탭에서 이미지 한 장을 레이어와 표정 파츠로 분리할 수 있습니다. 결과 갤러리의 레이어 편집기는 지우기, 생성 직후 픽셀 복원, 업로드 원본 복원, 레이어 순서 변경과 복원 레이어 병합을 지원합니다. 결과는 PSD, Unity V1 파츠 패키지 또는 V2 스켈레톤 초안으로 받을 수 있습니다.

이 기능은 Live2D Cubism `.moc3` 모델을 생성하지 않습니다. 분리된 파츠와 Anime2.5DRig/Unity 런타임으로 Live2D와 비슷한 효과를 만듭니다.

V2 결과를 Unity로 가져오려면 결과 갤러리에서 임포터를 한 번 설치한 뒤 **Unity에서 열기**를 사용합니다. 임포트할 때 필드용 월드 프리팹과 Canvas용 RenderTexture UI 프리팹이 함께 생성됩니다. 설치와 보안 방식은 [DOCS/UNITY_IMPORTER.md](DOCS/UNITY_IMPORTER.md)를 참고하세요.

개발·운영 구조, 공유 정책, API, 테스트와 배포 절차는 `G:\111\docs\LIVE2D_TOOL_HANDOFF.md`를 참고하세요. 레이어 편집 단축키와 원본 복원·병합 방법은 `G:\111\docs\LAYER_EDITING_GUIDE.md` 또는 웹의 **가이드** 탭에서 확인할 수 있습니다.

## YuE2 게임 BGM 도구

로그인 후 **게임 BGM** 탭에서 Markdown 기획서를 Gemini로 분석하거나 기본 프리셋·직접 프롬프트를 사용해 YuE2 음악을 생성할 수 있습니다. Google AI Studio API 키와 Vertex AI 서비스 계정을 지원하며, 보컬곡은 Style과 Lyrics를 분리해 전달합니다.

인스트루멘털 모드는 빈 섹션 구조로 악보를 계획한 뒤 ABC의 Vocal 음표를 같은 길이의 쉼표로 바꾸어 합성합니다. 설치와 사용자 설정은 [BGM_SETUP.md](BGM_SETUP.md), 개발·운영·테스트 인수인계는 [DOCS/YUE2_BGM_HANDOFF.md](DOCS/YUE2_BGM_HANDOFF.md)를 참고하세요.

## 먼저 확인하세요

**실사용을 시작할 권장 시스템 RAM은 32GB 이상입니다. GPU의 VRAM과는 별개입니다.**
32GB는 모든 해상도·모델에서 정상 동작을 보장하는 수치가 아닙니다. AMD INT8 인코더와 고해상도 영상은 RAM/VRAM 부담이 크며, 다른 프로그램을 함께 쓰면 더 여유 있는 메모리가 필요합니다.

현재 NVIDIA 경로는 RTX 5060 Ti 16GB에서 검증했습니다. AMD 경로는 Windows 11 + RX 9070 XT 16GB를 위한 **설치 옵션이며 이 저장소에서는 AMD 실생성을 아직 검증하지 않았습니다.**

## 빠른 시작

1. Git for Windows와 Python 3.12 x64를 설치한 뒤 저장소를 clone합니다.
2. NVIDIA는 `setup_windows.bat`
3. MiniMax H3 라이선스상 사용할 권한이 있는 경우에만 `download_h3_models.bat`
4. 팀 UI는 `start_team_tool.bat` (단독 UI는 `start_idle_tool.bat`, 동시 실행 금지)
5. 브라우저에서 `http://127.0.0.1:7866`

AMD는 **[AMD 설치 가이드](AMD_INSTALL.md)**를 먼저 읽고 `setup_windows_amd.bat` → `download_h3_models_amd.bat` → `start_team_tool_amd.bat` 순서로 진행합니다. 기존 NVIDIA 가상환경을 재사용하지 않습니다.

자세한 설치, 메모리 및 출력 설명은 [README_KO.md](README_KO.md)를 참고하세요.

## 생성 전 알아둘 점

- 기본 생성은 **일반 20스텝**입니다. 빠른 테스트는 Turbo 4스텝·3초·낮은 해상도로 시작하세요.
- RTX 5060 Ti에서 832×1216·5초·일반 20스텝이 약 24분 걸린 사례가 있습니다. 예전 Turbo 수십 초 기록과 같은 설정이 아닙니다.
- 시트 프레임을 8에서 64로 늘려도 AI 영상 생성 스텝은 늘지 않습니다. 잘 나온 영상은 갤러리에서 시트만 재추출하세요.
- 투명 PNG 입력도 생성 영상에서는 RGB 배경으로 합성됩니다. ‘배경 고정’은 투명 출력 기능이 아닙니다.
- 큰 시트는 게임 엔진의 텍스처 최대 크기와 메모리를 확인하세요. 비동기 로딩이 텍스처 메모리를 없애지는 않습니다.
- 완성 결과는 로그인 없이 공개 갤러리에서 볼 수 있습니다. 민감한 이미지/결과를 사용하지 마세요.
- 기능별 상세 안내는 웹의 **가이드 탭**에서도 확인할 수 있습니다.

## 팀 공동 사용

Live2D 레이어 편집기에서 2배·4배 확대본을 새 버전으로 적용하고 Unity V2까지 생성하거나, PSD·PNG 확대 파일만 다운로드할 수 있습니다. 적용본은 갤러리·내부 공유 링크에 반영됩니다. 사용법과 유지보수 내용은 [LIVE2D_UPSCALE.md](DOCS/LIVE2D_UPSCALE.md)를 참고하세요.

`start_team_tool.bat`으로 로그인·관리자 승인·공용 대기열·결과 갤러리가 있는 팀 서버를 실행합니다. 첫 관리자 등록과 외부 연결 준비는 [TEAM_SETUP.md](TEAM_SETUP.md)를 참고하세요. 기존 단독 서버와 동시에 실행하지 마세요.
