이미지의 특징을 먼저 분석해 주세요.

생성에 사용할 자세한 설명 보기 · 영어

공격 이펙트 · AI 생성

동작과 검기·섬광을 AI가 함께 만듭니다. 캐릭터와 효과는 하나의 시트로 저장됩니다.

효과의 색·모양·등장 시점을 적어 주세요. 큰 효과는 잘릴 수 있어 동작 여백 30%를 권장합니다. 투명 시트는 단색 배경 제거를 사용하며, 입력도 단순한 배경으로 준비해 주세요.

배경 윤곽을 정리하고, 캐릭터 색에 새 효과색을 더한 공통 팔레트(최대 48색)를 사용합니다. 단색 배경용 후처리이며 작은 명암이 단순해질 수 있습니다. 원본 영상도 함께 보존합니다.

선택 후 불러오기를 눌러 적용합니다. ‘사용 안 함’을 불러오면 현재 유형·동작의 기본 설명으로 돌아가며 다른 옵션은 유지합니다. 걷기·달리기는 팔·몸통·코트가 움직이는 영상 테스트 설정입니다. FastH3 / 512×512 / 3초 / 12프레임 / 강함 / 오른쪽 / 여백 10% / 루프 켜짐 / 자동 정규화·루프 구간 자동 선택 꺼짐을 적용합니다. 배경 제거 선택은 유지합니다. 조준 대기는 작은 좌우 체중 이동과 다리의 교대 보정을 허용하면서 조준선을 유지합니다. 인간형 / Idle / 약함 / 원본 방향 / 깜박임 없음 / 루프 켜짐 적용. 생성 모드·길이·해상도는 유지합니다.

유형 변경 시 동작 템플릿도 교체됩니다. 기계에는 눈 깜박임이 적용되지 않습니다.

선택한 동작 템플릿에 강도 지시를 추가합니다. 직접 쓴 동작 설명은 유지됩니다. 스텝·해상도는 바꾸지 않습니다.

생성 후 재생 시간을 조정합니다. 멈춤 정리는 반복하지 않는 공격에서 사용할 수 있으며, 원본 영상은 함께 보존됩니다.

투명 입력은 단색 배경 고정 지시를 자동 적용합니다. 프롬프트 제어이며 투명 출력이나 정확한 깜박임 횟수를 보장하지 않습니다. 동작 설명에 상충하는 배경·깜박임 지시를 넣지 마세요.

이미지를 넣으면 실제 크기를 계산합니다.

직접 입력 · 2~64프레임

입력 이미지를 비율 유지 축소하여 중앙 배치합니다. 10%는 좌우·상하 각각 약 5% 여유입니다. 출력 해상도는 유지되며 캐릭터 픽셀 크기는 줄어듭니다. 이미 잘린 부분은 복구되지 않습니다.

루프 동작을 선택했을 때 적용합니다. 자세와 이동 방향이 이어지는 구간을 찾아 원래 길이의 65% 이상을 유지합니다. 연결이 개선되는 경우에만 길이가 짧아집니다.

AI가 프레임별 배경을 제거합니다. 원본 영상과 시트는 함께 보존하며 영상 자체는 투명해지지 않습니다. 머리카락·반투명 소품은 결과를 확인하세요.

실험 · 별도 네거티브 프롬프트

추가 계산으로 느려지고 메모리 부담이 늘 수 있습니다. 4스텝 Turbo에서는 색·형태가 손상될 수 있는 실험 기능입니다. 동일 시드로 꺼짐/켜짐을 비교하세요.
