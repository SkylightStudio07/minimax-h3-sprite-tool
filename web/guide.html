시작하기

화면 구성

왼쪽 메뉴에서 만들기(캐릭터 원화·스프라이트·2D 리깅·게임 BGM)와 작업(내 작업·팀 갤러리·팀 대기열)을 오갑니다. 상단의 작업 표시기는 어느 화면에서든 내 작업의 진행 상태를 보여 주고, 끝나면 알림이 뜹니다.

작업은 보통 만들기 → 기다리기 → 다듬기 → 내보내기·공유 순서로 흐릅니다. 결과 카드를 누르면 결과 상세로 이동해 다운로드·편집·공유를 한곳에서 처리합니다. 각 화면 상단의 ?를 누르면 이 가이드의 해당 절이 열립니다.

처음 사용하는 순서

  1. 원본 이미지를 넣고 대상 유형과 애니메이션 종류를 선택하세요.
  2. 기본 Turbo v4로 먼저 만들어 보고, 결과를 보고 생성 모드와 길이를 결정하세요.
  3. 잘림이 걱정되면 동작 여백을 주고, 필요한 시트 프레임 수를 입력하세요.
  4. 생성을 등록한 뒤 팀 대기열에서 진행 상태를 확인하세요. 페이지를 닫아도 서버가 켜져 있으면 계속 처리합니다.
  5. 갤러리에서 영상·시트를 확인하고 다운로드하세요. 프레임 수만 바꾸려면 ‘시트 다시 추출’을 이용하세요.

캐릭터 원화

캐릭터 원화 만들기

  1. 이미지 스튜디오에서 새 이미지·원화 변환·부분 수정·4방향 시트 중 원하는 작업을 고르세요. 필요한 설정은 자동으로 준비됩니다.
  2. 외형과 의상을 설명하고, 그림체는 우측 패널에서 예시를 보고 선택하세요. 기존 원화를 변환할 때는 방향과 자세도 조정할 수 있어요.
  3. 여러 후보 중 원하는 결과를 고르세요. 부분 수정에서는 바꿀 부분만 붉게 칠합니다. B 칠하기 · E 지우기 · Ctrl+Z 되돌리기.
  4. PNG 저장·동작 만들기·Live2D 만들기로 이어 가세요. 결과는 팀 갤러리에도 자동 저장됩니다. 눈·입 리깅 마스크는 Live2D에서 별도로 지정합니다.

원화는 승인된 팀원만 볼 수 있습니다. 흰 배경 지시는 투명 PNG를 보장하지 않아요. 모델마다 라이선스가 다르며 선택 화면에서 확인할 수 있어요.

캐릭터 원화 시작

캐릭터별 작업 모으기 · 프레임 수정

  1. 캐릭터 작업실에서 묶음을 만들고 대표 원화와 기존 결과를 연결하세요. 원화·그림체·방향·동작으로 분류할 수 있습니다.
  2. 묶음에서 생성을 시작하면 연결 대상이 화면에 표시됩니다. 대표 원화와 보관한 그림체·세팅을 가져오고 새 결과를 자동 연결할 수 있어요.
  3. 스프라이트 결과의 프레임 편집에서 열·행을 확인하고, 좋은 프레임을 고정하세요. 고칠 프레임의 얼굴·손 등을 B로 칠하고 수정 후보를 만듭니다.
  4. 앞뒤 프레임과 비교해 적용하면 새 버전이 저장됩니다. PNG·시트 ZIP으로 내보내거나 이전 버전으로 복원할 수 있어요. 원본 영상은 그대로입니다.

스프라이트

생성 모드 · 길이 · 해상도

Turbo v4 8스텝 — 기본
768×768·3초 기준 약 3분입니다. 프롬프트에 없는 소품이 생기거나 동작이 커지면 설명을 짧게 줄이거나 고화질 모드와 비교해 보세요.
고화질 20스텝
Turbo v4보다 약 2배 오래 걸립니다. 이 PC에서 832×1216·5초는 약 24분 걸린 사례가 있습니다.
이전 Turbo 4스텝
동작만 빠르게 확인하는 용도입니다. 배경이나 형태가 달라질 수 있습니다.
길이
3초 또는 5초. 길수록 생성 부담이 커집니다. 모델의 프레임 규칙 때문에 실제 영상 길이는 약간 달라질 수 있습니다.
해상도
자동 옵션은 원본 비율을 참고하고 모델 단위에 맞춰 크기를 조정합니다. 높은 해상도는 더 느리고 메모리를 많이 사용합니다.
동작 여백
없음·10%·20%·30%. 기본 10%는 입력을 90% 크기로 줄여 중앙 배치합니다. 양쪽에 약 5%씩 여유가 생기며 출력 해상도는 그대로입니다. 캐릭터 픽셀 크기는 줄고, 이미 잘린 부분을 복구하지는 못합니다.

대상 유형 · 동작

인간형
호흡·체중 이동·머리카락과 옷자락 등 사람 중심 템플릿입니다.
생물 / 괴물
원본에 있는 몸과 부속 기관으로 움직이도록 지시합니다.
부유 기계
부유와 기존 기계 관절 움직임을 사용하고 장갑판·총열의 단단한 구조를 유지하도록 지시합니다.
지상 기계
기존 바퀴·궤도·지지 관절과 지면 접촉을 기준으로 움직입니다.
애니메이션 종류
Idle은 지속 대기, Walk/Run은 제자리 이동, Attack은 공격, Cast는 스킬, Hit는 피격, Death는 사망, Jump는 점프, Custom은 직접 설명입니다. 유형에 따라 같은 동작의 설명도 달라집니다.

유형 변경은 동작 설명을 교체합니다. 직접 작성한 설명이 있으면 교체 확인창이 표시됩니다. 원본에 없는 기관·부품을 요구하지 않도록 설명을 확인하세요.

프롬프트와 세팅 모음

세팅 모음
선택 후 ‘불러오기’를 눌러 적용합니다. ‘사용 안 함’을 불러오면 현재 유형·동작의 기본 설명으로 돌아가고 다른 옵션은 유지합니다.
조준 대기
인간형·Idle·약함·원본 방향·깜박임 없음·루프 켜짐을 적용합니다. 작은 체중 이동과 호흡을 팔이 보상해 조준선을 유지하도록 지시합니다. 길이·해상도·생성 모드는 바꾸지 않습니다.
움직임 강도
약함·보통·강함. 기본은 보통입니다. 프롬프트의 동작 크기를 조절하며, 강할수록 형태 변형이나 잘림 위험이 있습니다. 스텝 수는 바뀌지 않습니다.
방향 고정 / 눈 깜박임
원본 방향 또는 지정 방향을 유지하도록 지시합니다. 눈은 없음 또는 최대 한 번이며 기계에는 적용하지 않습니다. 정확한 방향·횟수를 보장하지는 않습니다.
동작 설명 / 템플릿 불러오기
움직일 부위와 유지할 부위를 구체적으로 적으세요. 불러오기는 설명을 기본 템플릿으로 교체합니다. ‘모든 부위 고정’과 ‘크게 움직임’처럼 상충하는 지시는 피하세요.

영상으로 걷기·달리기 만들기

스프라이트 시트 도구의 세팅 모음에서 걷기 또는 달리기 영상 테스트 세팅을 불러오세요. 팔·몸통·코트까지 연속으로 움직이는 영상을 생성한 뒤, 결과 화면의 반복 구간 고르기에서 영상의 시작·끝을 지정하고 연결을 비교한 뒤 원하는 장수로 시트를 저장합니다. 프레임별 포즈 생성 실험은 종료했습니다.

스프라이트 시트 도구 열기

루프 · 정규화 · 실험 옵션

루프
시작·끝에 같은 참조 이미지를 사용해 연결을 유도합니다. 완벽한 연결을 보장하지 않습니다. 죽음처럼 마지막 자세가 달라야 하는 동작은 꺼두세요.
크기·프레이밍 정규화
영상 생성 후 캐릭터 배치를 보정합니다. 분석이 부정확하면 결과가 어색할 수 있으니 H3 원본과 비교하세요. 동작 여백 사용 시 추가 확대는 제한됩니다.
CFG 네거티브 — 기본 꺼짐
억제할 내용을 별도 입력하는 실험 기능입니다. 추가 계산·메모리 부담이 있고 형태나 색이 손상될 수 있습니다. 강도 범위는 1.1~2.0입니다.
Seed
비우면 무작위입니다. 설정을 비교할 때 같은 값을 쓰면 비교에 도움이 되지만 완전히 동일한 결과를 보장하지는 않습니다.

시트 · 누끼 · 재추출

시트 프레임
2~64장, 기본 8장. 생성 영상에서 고르게 골라 최대 8열로 배치합니다. 프레임 수를 늘려도 영상 생성 스텝은 늘지 않지만 시트 크기와 메모리 사용량은 커집니다.
단색 배경 누끼 — 기본 꺼짐
가장자리와 연결된 비슷한 배경색을 제거해 별도 투명 PNG 시트를 만듭니다. 강도는 4~64입니다. 의상·머리카락이 손상되거나 닫힌 공간의 배경이 남을 수 있습니다. 원본 시트·영상은 보존하며 영상 자체는 투명해지지 않습니다.
AI · 윤곽 다듬기 — 실험적
AI 배경 제거 후 윤곽의 끊김과 계단을 정리하고 앞뒤 프레임과 맞춥니다. 내부 색과 떨어져 있는 섬광·연기는 그대로 두며, 일반 AI 방식보다 오래 걸립니다.
갤러리 → 시트 다시 추출
기존 생성 영상에서 2~64프레임을 다시 뽑습니다. AI 생성 없이 원본 시트를 보존하고 별도 다운로드 링크를 추가합니다. 누끼는 적용하지 않습니다. 본인 결과 또는 관리자만 실행할 수 있습니다.

2D 리깅 만들기

리깅 생성부터 Unity까지

리깅은 원본을 자동으로 완성하는 단계가 아니라, 분리 결과를 확인하고 필요한 부분을 직접 고쳐 내보내는 작업입니다. 2D 리깅 작업 화면에서 이미지를 올린 뒤 마스크 가이드에 따라 눈과 입을 지정하세요.

  • 분리 엔진: See-through가 기본입니다. Qwen 2.1은 원본의 후드·안경·복잡한 의상을 보존하도록 돕는 실험 옵션이며, 결과를 원본과 꼭 비교하세요.
  • 눈 입력: 눈 전체를 칠하는 쉬운 영역 모드와, 실제 눈 기울기를 따라 감은 선을 그리는 모드가 있습니다. 기본적으로 원본 눈 픽셀을 보존할 수 있고, 얇은 눈썹은 선택적으로 마스크해 보존합니다.
  • 입: 입술과 입 안만 작게 지정하고, 원본 상태가 닫혔는지 살짝 열렸는지 고릅니다.
  • 게임 스프라이트: 측면·교차 자세는 게임 스프라이트 모드를 고르고 안내된 관절점을 직접 찍습니다. 관절 위치를 확인한 다음 패키지를 만드세요.
  • Unity 출력: V1은 레이어 파츠 중심이고, V2는 전신 본·메시·자동 웨이트가 추가된 보정용 초안입니다. V2는 Unity에서 본 위치와 웨이트를 확인해야 합니다.
후드·귀마개·안경·코트 같은 원본 파츠가 빠지거나 잘못 분리되면 생성만 반복하기보다 편집기에서 R로 원본 픽셀을 복원하세요. 이후 적절한 레이어에 병합하거나 독립 레이어로 두고 가림 순서를 확인하면 됩니다.

눈 마스크 · 쉬운 영역 칠하기

마우스 사용자와 정면·3/4 얼굴에 권장합니다.

  • 흰자·홍채·동공·속눈썹을 함께 덮기
  • 눈 윤곽 밖으로 2~4px만 여유 두기
  • 눈썹·코·앞머리·넓은 피부는 제외

눈 마스크 · 감은 눈 선 직접 그리기

기울어진 눈이나 펜 입력에 권장합니다.

  • 안쪽 눈꼬리에서 바깥쪽까지 한 획
  • 원본 눈꼬리의 실제 기울기를 그대로 따르기
  • 눈 전체 칠하기·눈썹 따라 그리기 금지

리깅 스튜디오

편집기는 어디서 열어요?

2D 리깅 결과가 나온 뒤 결과 카드 또는 생성 화면의 레이어 수정을 눌러 편집기를 엽니다. 내부 공유 링크에서도 레이어 편집을 사용할 수 있습니다.

본인 결과나 관리자 권한으로 편집할 수 있습니다. 내부 공유 링크를 받은 사람은 로그인 없이 편집할 수 있습니다.

안전한 기본 작업 순서

1 · 확인레이어를 고르고 확대합니다. 누르는 동안 저장본으로 편집 전과 비교하고, 원본 겹치기로 위치를 맞춥니다.
2 · 수정E로 필요 없는 부분을 지웁니다. 누락된 원본은 R, 생성 때부터 잘못 잘린 파츠는 B로 복원합니다.
3 · 저장레이어 순서와 표시 상태를 확인하고 PSD와 패키지에 저장을 누릅니다. 새 작업 버전으로 보존됩니다.

도구와 단축키

도구/키하는 일
V 선택캔버스의 파츠나 오른쪽 레이어 목록에서 편집할 레이어를 선택합니다.
B 복원선택한 레이어의 생성 직후 픽셀을 되살립니다.
R 원본업로드 원본 픽셀을 새 복원 레이어에 칠합니다. 후드·머리 장식·옷/코트·장비·고정 파츠 중 종류를 고릅니다.
E 지우개선택 레이어 일부를 지워 아래쪽 레이어를 드러냅니다.
Ctrl+Z / Ctrl+Y저장 전 편집을 되돌리거나 다시 적용합니다. Ctrl+Shift+Z도 다시 실행입니다.
드래그 / ▲ ▼레이어 순서를 바꿉니다. 목록 위쪽의 레이어가 화면 앞에 놓입니다.

B와 R은 달라요. B는 그 레이어가 처음 생성됐을 때의 픽셀을 되살립니다. R은 업로드 원본의 픽셀을 별도 레이어에 가져옵니다.

수정하면서 Live2D 움직임 확인

편집기 상단 Live2D 미리보기를 누르면 캔버스 옆에서 바로 재생됩니다. 지우개·복원·그리기를 마치거나 레이어 표시·순서를 바꾸면 저장 전 내용도 자동 반영됩니다. 지금 반영으로 바로 갱신할 수 있습니다.

깜박임·입 움직임·대기 동작을 따로 켜고 끄거나 일시정지하고, 미리보기 안에서 휠 확대·드래그 이동으로 확인하세요. 내부 공유 편집기도 지원합니다. 결과물에 남기려면 PSD와 패키지에 저장을 눌러야 합니다. 본·IK·타임라인 조작은 포즈 테스트에서 확인합니다.

원본 복원 레이어를 기존 레이어에 합치기

  1. R 도구를 고르고 복원 종류를 선택합니다.
  2. 캔버스에서 필요한 파츠를 칠합니다. 우측 패널에서 원본 복원 · ... 레이어를 선택합니다.
  3. 레이어 병합에서 대상을 고릅니다. 같은 종류의 파츠가 추천 대상으로 표시됩니다.
  4. 미리보기를 확인합니다. 괜찮으면 저장하고, 틀리면 저장 전에 Ctrl+Z로 병합을 취소합니다.
  • 후드나 귀마개가 기존 머리 장식과 같은 순서로 움직여야 하면 headwear에 병합합니다.
  • 후드가 목·어깨·코트까지 이어져 몸통과 함께 움직여야 하면 topwear가 알맞을 수 있습니다.
  • 기존 레이어가 잘못 분리됐거나 별도 움직임·가림 순서가 필요하면 복원 레이어를 따로 유지합니다.
  • 귀마개·헤어밴드는 머리카락 흔들림에 섞이지 않도록 머리 장식 레이어로 관리합니다. 옆머리의 앞과 뒤를 모두 지나가면 앞·뒤 파츠 분리를 고려합니다.
병합한 뒤 추가 브러시 작업을 하려면 먼저 저장하거나 병합을 취소하세요. 병합은 저장 전 편집 기록으로 취급됩니다.

눈·입·눈썹 표정 차분 직접 그리기

  1. 레이어 편집기의 우측 표정 차분에서 바꿀 슬롯을 고릅니다. 원본을 보관하려면 먼저 현재 파츠 복제를 사용하세요.
  2. 이름을 적고 빈 차분 만들기를 누릅니다. P 색상 브러시로 그리고 E로 지웁니다. 색상·크기 조절과 Ctrl+Z 취소를 지원합니다.
  3. 원래 파츠를 25%로 참고할 수 있습니다. 참고 이미지는 저장되지 않습니다. 감은 눈은 좌우 슬롯을 따로 작업하고, 눈썹은 눈과 별도로 다루세요.
  4. 투명 PNG 가져오기도 가능합니다. 전체 캔버스 크기 또는 선택한 차분 크기의 PNG를 사용하세요. 전체 PNG는 차분 영역만 잘라 가져옵니다.
  5. 선택 차분을 움직임에 적용 후 PSD와 패키지에 저장을 누릅니다. 차분은 기존 슬롯을 교체하며, 보관 레이어가 원래 눈 위에 중복 표시되지 않습니다.
보관 차분은 레이어 패널에서 선택해 다시 적용할 수 있습니다. 적용하지 않고 저장하면 보관만 됩니다. Unity V1 ZIP은 저장본을 사용하고 V2는 다시 생성하세요. 공개본은 관리자 갱신이 필요합니다.

감긴 눈·입·장비만 다시 생성

우측 눈·입·장비 다시 생성에서 파츠를 고르고 다시 생성하세요. 원본 참고·현재 레이어·새 후보를 비교한 뒤 이 파츠에 적용 → PSD와 패키지에 저장합니다. 다른 파츠는 그대로 유지됩니다.

눈·입은 AI로 다시 그리고, 장비(object)는 원본을 다시 분리한 결과 중 선택 위치만 가져옵니다. 피부색·앞머리·눈썹이 함께 변하지 않았는지 확인하세요. 닫으면 기존 결과를 유지하며, 적용은 Ctrl+Z, 저장 후에는 버전 복원으로 되돌릴 수 있습니다.

수정 사항은 먼저 저장/취소해야 합니다. 공개 워크스페이스가 아니라 작업 편집기 또는 내부 공유에서 사용할 수 있습니다.

본 위치·연결과 포즈 테스트

  1. 레이어·표정 편집은 먼저 저장한 뒤 편집기 상단 본 위치·연결을 고릅니다.
  2. 관절점을 드래그하거나 좌표를 입력합니다. 원래 픽셀은 그대로이며, 부모 본과 파츠가 따를 본을 조정할 수 있습니다.
  3. 레이어 목록에서 머리카락·코트·토시를 선택하고 선택 파츠에 유연 조작점 추가를 누릅니다. 뿌리와 끝을 그림에 맞추세요.
  4. 포즈 테스트에서 점을 드래그하거나 회전하면 메시와 자식 본이 움직입니다. 포즈 취소·재실행·초기화를 지원합니다. 테스트 포즈는 저장되지 않습니다.
  5. 본 설정은 PSD와 패키지에 저장으로 새 버전에 기록하고 저장본으로 Unity V2 생성을 누릅니다. PSD 픽셀은 그대로이며 본·웨이트는 ZIP에 들어갑니다.
손·발 IK와 타임라인을 지원합니다. 키로 기록한 동작만 저장됩니다. 큰 자세 변화로 빈 부분이 드러나면 레이어 보정이 필요합니다.

IK·타임라인으로 동작 기록

  1. 포즈 테스트에서 손·발 IK를 켜고 손목·발목을 드래그합니다. 팔꿈치·무릎이 접히며 굽힘 반전도 가능합니다. Alt 드래그는 자유 이동입니다.
  2. 0프레임에서 키 추가·갱신을 누르고, 다른 프레임에 다음 자세를 기록합니다. 자동 키는 포즈 조작을 마칠 때 기록합니다.
  3. 키 이동·삭제·복사/붙여넣기와 키 편집 취소를 지원합니다. 키는 전체 자세를 기록합니다.
  4. 이름·FPS·길이·반복·보간은 클립 설정 적용으로 바꿉니다. 재생과 프레임 슬라이더로 확인하세요.
  5. PSD와 패키지에 저장 → Unity V2 생성으로 기록합니다. 원본 픽셀은 그대로입니다. Unity에서 클립을 쓰려면 최신 임포터 0.4.0으로 업데이트하세요.

크게 띄우면 흐려질 때 · 화질 개선

리깅 스튜디오 상단의 화질 개선을 누르세요. AI 선·채색 개선과 일반 확대를 고를 수 있고, 우선 2배로 비교하는 것을 권장합니다.

수정 내용을 먼저 저장한 뒤 화질 개선본 적용 · 새 버전 저장을 누르면 레이어·표정·PSD·Unity V2와 갤러리·내부 공유에 반영됩니다. 파일만 필요하면 확대 파일만 다운로드를 사용하세요.

이전 버전으로 복원할 수 있습니다. 반복 적용하면 배율이 누적됩니다. AI는 선을 다듬지만 사라진 디테일을 정확히 되살리는 기능은 아닙니다.

저장과 버전

  • 저장하면 합성 미리보기, PSD, Unity V1 파츠 ZIP이 새 버전으로 만들어집니다.
  • 병합한 복원 레이어는 결과에서 제거되고 대상 파츠에 포함됩니다.
  • V2 패키지는 이전 revision 기준이므로 필요하면 다시 생성합니다.
  • 내부 공유 링크에는 현재 버전이 보입니다. 공개 Live2D는 게시 당시 스냅샷을 유지하므로 관리자가 갤러리에서 공개본 갱신을 해야 바뀝니다.
  • 저장 후 되돌리려면 상단 버전 선택기에서 과거 버전을 고르고 선택 버전 복원을 누릅니다. 복원도 새 버전으로 기록됩니다.

대기열과 계정

팀 대기열 · 갤러리 · 계정

생성은 등록 순서대로 한 번에 하나씩 처리합니다. 개인 최대 3개, 전체 최대 20개까지 대기 작업을 등록할 수 있습니다. 대기열에서 작업자와 원본 이미지를 확인하며 대기 중인 본인 작업은 취소할 수 있습니다.

완료 영상과 시트는 로그인 전 공개 갤러리에서도 볼 수 있습니다. 민감한 결과는 업로드·생성 전에 공개 범위를 고려하세요. 생성과 재추출은 승인 계정이 필요합니다.

갤러리의 ‘결과 삭제’는 본인 또는 관리자만 가능합니다. 공개 갤러리와 다운로드에서 빠지지만 복구용 파일과 기록은 서버에 보관되므로 디스크 영구 삭제는 아닙니다.

관리자는 ‘계정 승인’에서 가입 요청을 승인하거나 이용을 제한할 수 있습니다.

문제 해결

스프라이트 결과가 이상할 때

  • 잘림: 동작 여백을 늘리거나 움직임 강도를 낮추세요. 원본 이미지부터 잘린 부분은 복구되지 않습니다.
  • 몸 전체가 들썩임: 움직일 부위를 좁히고 조준 대기 같은 세팅을 활용하세요.
  • 배경 생성: 단색 배경 지시도 완벽하지 않습니다. 원본 입력과 다른 설정으로 비교하세요.
  • 오래 걸림: 일반 20스텝·고해상도·긴 영상은 느립니다. 팀 대기열에서 상태를 먼저 확인하세요.
  • 옵션 변경: 이미 등록한 작업에는 소급 적용되지 않습니다. 설정을 바꾼 뒤 새 작업을 등록하세요.

리깅 편집에서 문제가 생기면

  • 복원한 부분이 가려짐: 레이어 순서를 조정합니다. 앞과 뒤로 동시에 지나가는 파츠는 한 레이어로 표현하기 어려울 수 있습니다.
  • 원본 픽셀이 어긋남: 원본 겹치기와 투명도를 사용해 윤곽을 맞춥니다. 재연결할 땐 생성에 사용한 같은 이미지를 선택합니다.
  • 병합 버튼이 없음: R로 만든 복원 레이어를 선택했는지 확인합니다.
  • V2/공개본이 그대로임: V2는 새로 만들고 공개 Live2D는 관리자가 갱신합니다.
  • 페이지를 닫았음: 저장하지 않은 변경은 남지 않습니다. 저장 후에는 버전 복원으로 되돌립니다.
