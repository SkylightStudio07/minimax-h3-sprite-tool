팀 작업공간2D 리깅

편집기는 어디서 열어요?

팀 작업공간의 가이드 탭에서 이 안내를 열 수 있습니다. 2D 리깅 결과가 나온 뒤 결과 카드 또는 생성 화면의 레이어 수정을 눌러 편집기를 엽니다. 내부 공유 링크에서도 레이어 편집을 사용할 수 있습니다.

본인 결과나 관리자 권한으로 편집할 수 있습니다. 내부 공유 링크는 링크를 가진 팀원이 편집할 수 있습니다.

리깅 생성부터 Unity까지

리깅은 원본을 자동으로 완성하는 단계가 아니라, 분리 결과를 확인하고 필요한 부분을 직접 고쳐 내보내는 작업입니다. 2D 리깅 작업 화면에서 이미지를 올린 뒤 마스크 가이드에 따라 눈과 입을 지정하세요.

  • 분리 엔진: See-through가 기본입니다. Qwen 2.1은 원본의 후드·안경·복잡한 의상을 보존하도록 돕는 실험 옵션이며, 결과를 원본과 꼭 비교하세요.
  • 눈 입력: 눈 전체를 칠하는 쉬운 영역 모드와, 실제 눈 기울기를 따라 감은 선을 그리는 모드가 있습니다. 기본적으로 원본 눈 픽셀을 보존할 수 있고, 얇은 눈썹은 선택적으로 마스크해 보존합니다.
  • 입: 입술과 입 안만 작게 지정하고, 원본 상태가 닫혔는지 살짝 열렸는지 고릅니다.
  • 게임 스프라이트: 측면·교차 자세는 게임 스프라이트 모드를 고르고 안내된 관절점을 직접 찍습니다. 관절 위치를 확인한 다음 패키지를 만드세요.
  • Unity 출력: V1은 레이어 파츠 중심이고, V2는 전신 본·메시·자동 웨이트가 추가된 보정용 초안입니다. V2는 Unity에서 본 위치와 웨이트를 확인해야 합니다.
후드·귀마개·안경·코트 같은 원본 파츠가 빠지거나 잘못 분리되면 생성만 반복하기보다 편집기에서 R로 원본 픽셀을 복원하세요. 이후 적절한 레이어에 병합하거나 독립 레이어로 두고 가림 순서를 확인하면 됩니다.

도구와 단축키

도구/키하는 일
V 선택캔버스의 파츠나 오른쪽 레이어 목록에서 편집할 레이어를 선택합니다.
B 복원선택한 레이어의 생성 직후 픽셀을 되살립니다.
R 원본업로드 원본 픽셀을 새 복원 레이어에 칠합니다. 후드·머리 장식·옷/코트·장비·고정 파츠 중 종류를 고릅니다.
E 지우개선택 레이어 일부를 지워 아래쪽 레이어를 드러냅니다.
Ctrl+Z / Ctrl+Y저장 전 편집을 되돌리거나 다시 적용합니다. Ctrl+Shift+Z도 다시 실행입니다.
드래그 / ▲ ▼레이어 순서를 바꿉니다. 목록 위쪽의 레이어가 화면 앞에 놓입니다.
Space+드래그확대한 캔버스를 이동합니다.
Ctrl+휠마우스 위치를 기준으로 확대·축소합니다. Ctrl+0은 화면 맞춤, Ctrl+1은 100%입니다.
[ / ]브러시 크기를 줄이거나 키웁니다.
B와 R은 달라요. B는 그 레이어가 처음 생성됐을 때의 픽셀을 되살립니다. R은 업로드 원본의 픽셀을 별도 레이어에 가져옵니다.

수정하면서 Live2D 움직임 확인

편집기 상단 Live2D 미리보기를 누르면 캔버스 옆에서 바로 재생됩니다. 지우개·복원·그리기를 마치거나 레이어 표시·순서를 바꾸면 저장 전 내용도 자동 반영됩니다. 지금 반영으로 바로 갱신할 수 있습니다.

깜박임·입 움직임·대기 동작을 따로 켜고 끄거나 일시정지하고, 미리보기 안에서 휠 확대·드래그 이동으로 확인하세요. 내부 공유 편집기도 지원합니다. 결과물에 남기려면 PSD와 패키지에 저장을 눌러야 합니다. 본·IK·타임라인 조작은 포즈 테스트에서 확인합니다.

안전한 기본 작업 순서

1 · 확인레이어를 고르고 확대합니다. `누르는 동안 저장본`으로 편집 전과 비교하고, `원본 겹치기`로 위치를 맞춥니다.
2 · 수정E로 필요 없는 부분을 지웁니다. 누락된 원본은 R, 생성 때부터 잘못 잘린 파츠는 B로 복원합니다.
3 · 저장레이어 순서와 표시 상태를 확인하고 `PSD와 패키지에 저장`을 누릅니다. 새 작업 버전으로 보존됩니다.

원본 복원 레이어를 기존 레이어에 합치기

  1. R 도구를 고르고 복원 종류를 선택합니다.
  2. 캔버스에서 필요한 파츠를 칠합니다. 우측 패널에서 `원본 복원 · ...` 레이어를 선택합니다.
  3. `레이어 병합`에서 대상을 고릅니다. 같은 종류의 파츠가 추천 대상으로 표시됩니다.
  4. 미리보기를 확인합니다. 괜찮으면 저장하고, 틀리면 저장 전에 Ctrl+Z로 병합을 취소합니다.
  • 후드나 귀마개가 기존 머리 장식과 같은 순서로 움직여야 하면 headwear에 병합합니다.
  • 후드가 목·어깨·코트까지 이어져 몸통과 함께 움직여야 하면 topwear가 알맞을 수 있습니다.
  • 기존 레이어가 잘못 분리됐거나 별도 움직임·가림 순서가 필요하면 복원 레이어를 따로 유지합니다.
  • 귀마개·헤어밴드는 머리카락 흔들림에 섞이지 않도록 머리 장식 레이어로 관리합니다. 옆머리의 앞과 뒤를 모두 지나가면 앞·뒤 파츠 분리를 고려합니다.
병합한 뒤 추가 브러시 작업을 하려면 먼저 저장하거나 병합을 취소하세요. 병합은 저장 전 편집 기록으로 취급됩니다.

저장과 버전

  • 저장하면 합성 미리보기, PSD, Unity V1 파츠 ZIP이 새 버전으로 만들어집니다.
  • 병합한 복원 레이어는 결과에서 제거되고 대상 파츠에 포함됩니다.
  • V2 패키지는 이전 revision 기준이므로 필요하면 다시 생성합니다.
  • 내부 공유 링크에는 현재 버전이 보입니다. 공개 Live2D는 게시 당시 스냅샷을 유지하므로 관리자가 갤러리에서 `공개본 갱신`을 해야 바뀝니다.
  • 저장 후 되돌리려면 상단 버전 선택기에서 과거 버전을 고르고 `선택 버전 복원`을 누릅니다. 복원도 새 버전으로 기록됩니다.

문제가 생기면

  • 복원한 부분이 가려짐: 레이어 순서를 조정합니다. 앞과 뒤로 동시에 지나가는 파츠는 한 레이어로 표현하기 어려울 수 있습니다.
  • 원본 픽셀이 어긋남: `원본 겹치기`와 투명도를 사용해 윤곽을 맞춥니다. 재연결할 땐 생성에 사용한 같은 이미지를 선택합니다.
  • 병합 버튼이 없음: R로 만든 복원 레이어를 선택했는지 확인합니다.
  • V2/공개본이 그대로임: V2는 새로 만들고 공개 Live2D는 관리자가 갱신합니다.
  • 페이지를 닫았음: 저장하지 않은 변경은 남지 않습니다. 저장 후에는 버전 복원으로 되돌립니다.

눈·입·눈썹 표정 차분 직접 그리기

  1. 레이어 편집기의 우측 표정 차분에서 바꿀 슬롯을 고릅니다. 원본을 보관하려면 먼저 현재 파츠 복제를 사용하세요.
  2. 이름을 적고 빈 차분 만들기를 누릅니다. P 색상 브러시로 그리고 E로 지웁니다. 색상·크기 조절과 Ctrl+Z 취소를 지원합니다.
  3. 원래 파츠를 25%로 참고할 수 있습니다. 참고 이미지는 저장되지 않습니다. 감은 눈은 좌우 슬롯을 따로 작업하고, 눈썹은 눈과 별도로 다루세요.
  4. 투명 PNG 가져오기도 가능합니다. 전체 캔버스 크기 또는 선택한 차분 크기의 PNG를 사용하세요. 전체 PNG는 차분 영역만 잘라 가져옵니다.
  5. 선택 차분을 움직임에 적용 후 PSD와 패키지에 저장을 누릅니다. 차분은 기존 슬롯을 교체하며, 보관 레이어가 원래 눈 위에 중복 표시되지 않습니다.
보관 차분은 레이어 패널에서 선택해 다시 적용할 수 있습니다. 적용하지 않고 저장하면 보관만 됩니다. Unity V1 ZIP은 저장본을 사용하고 V2는 다시 생성하세요. 공개본은 관리자 갱신이 필요합니다.

본 위치·연결과 포즈 테스트

  1. 레이어·표정 편집은 먼저 저장한 뒤 편집기 상단 본 위치·연결을 고릅니다.
  2. 관절점을 드래그하거나 좌표를 입력합니다. 원래 픽셀은 그대로이며, 부모 본과 파츠가 따를 본을 조정할 수 있습니다.
  3. 레이어 목록에서 머리카락·코트·토시를 선택하고 선택 파츠에 유연 조작점 추가를 누릅니다. 뿌리와 끝을 그림에 맞추세요.
  4. 포즈 테스트에서 점을 드래그하거나 회전하면 메시와 자식 본이 움직입니다. 포즈 취소·재실행·초기화를 지원합니다. 테스트 포즈는 저장되지 않습니다.
  5. 본 설정은 PSD와 패키지에 저장으로 새 버전에 기록하고 저장본으로 Unity V2 생성을 누릅니다. PSD 픽셀은 그대로이며 본·웨이트는 ZIP에 들어갑니다.
손·발 IK와 타임라인을 지원합니다. 키로 기록한 동작만 저장됩니다. 큰 자세 변화로 빈 부분이 드러나면 레이어 보정이 필요합니다.

IK·타임라인으로 동작 기록

  1. 포즈 테스트에서 손·발 IK를 켜고 손목·발목을 드래그합니다. 팔꿈치·무릎이 접히며 굽힘 반전도 가능합니다. Alt 드래그는 자유 이동입니다.
  2. 0프레임에서 키 추가·갱신을 누르고, 다른 프레임에 다음 자세를 기록합니다. 자동 키는 포즈 조작을 마칠 때 기록합니다.
  3. 키 이동·삭제·복사/붙여넣기와 키 편집 취소를 지원합니다. 키는 전체 자세를 기록합니다.
  4. 이름·FPS·길이·반복·보간은 클립 설정 적용으로 바꿉니다. 재생과 프레임 슬라이더로 확인하세요.
  5. PSD와 패키지에 저장 → Unity V2 생성으로 기록합니다. 원본 픽셀은 그대로입니다. Unity에서 클립을 쓰려면 최신 임포터 0.4.0으로 업데이트하세요.

크게 띄우면 흐려질 때 · 화질 개선

리깅 스튜디오 상단의 화질 개선을 누르세요. AI 선·채색 개선과 일반 확대를 고를 수 있고, 우선 2배로 비교하는 것을 권장합니다.

수정 내용을 먼저 저장한 뒤 화질 개선본 적용 · 새 버전 저장을 누르면 레이어·표정·PSD·Unity V2와 갤러리·내부 공유에 반영됩니다. 파일만 필요하면 확대 파일만 다운로드를 사용하세요.

이전 버전으로 복원할 수 있습니다. 반복 적용하면 배율이 누적됩니다. AI는 선을 다듬지만 사라진 디테일을 정확히 되살리는 기능은 아닙니다.

감긴 눈·입·장비만 다시 생성

우측 눈·입·장비 다시 생성에서 파츠를 고르고 다시 생성하세요. 원본 참고·현재 레이어·새 후보를 비교한 뒤 이 파츠에 적용 → PSD와 패키지에 저장합니다. 다른 파츠는 그대로 유지됩니다.

눈·입은 AI로 다시 그리고, 장비(object)는 원본을 다시 분리한 결과 중 선택 위치만 가져옵니다. 피부색·앞머리·눈썹이 함께 변하지 않았는지 확인하세요. 닫으면 기존 결과를 유지하며, 적용은 Ctrl+Z, 저장 후에는 버전 복원으로 되돌릴 수 있습니다.

수정 사항은 먼저 저장/취소해야 합니다. 공개 워크스페이스가 아니라 작업 편집기 또는 내부 공유에서 사용할 수 있습니다.
