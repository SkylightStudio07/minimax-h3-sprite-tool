결과 갤러리

승인된 팀원의 생성 영상과 스프라이트 시트입니다. 한 페이지에 6개씩 표시합니다. 영상은 재생 시 로딩되며 시트는 다운로드로 확인하세요.

공개 Live2D 목록 열기

계정 승인

가입 요청을 승인하면 생성·대기열·공용 결과에 접근할 수 있습니다. 이용 제한 시 대기 작업은 취소되며 진행 중인 작업은 끝까지 실행됩니다.

사용 가이드

이미지 → 영상 생성 → 시트 추출. 영상 생성과 시트 프레임 수는 별개입니다.

처음 사용하는 순서

  1. 원본 이미지를 넣고 대상 유형과 애니메이션 종류를 선택하세요.
  2. 빠른 확인은 Turbo·3초로, 본 작업은 결과를 보고 생성 모드와 길이를 결정하세요.
  3. 잘림이 걱정되면 동작 여백을 주고, 필요한 시트 프레임 수를 입력하세요.
  4. 생성을 등록한 뒤 팀 대기열에서 진행 상태를 확인하세요. 페이지를 닫아도 서버가 켜져 있으면 계속 처리합니다.
  5. 갤러리에서 영상·시트를 확인하고 다운로드하세요. 프레임 수만 바꾸려면 ‘시트 다시 추출’을 이용하세요.

생성 모드 · 길이 · 해상도

일반 20스텝 — 기본
Turbo보다 오래 걸립니다. 일부 비교에서 배경 유지가 좋았지만 모든 입력의 품질을 보장하지 않습니다. 이 PC에서 832×1216·5초는 약 24분 걸린 사례가 있습니다.
Turbo 4스텝
빠른 테스트용입니다. 배경이나 형태가 달라질 수 있습니다.
길이
3초 또는 5초. 길수록 생성 부담이 커집니다. 모델의 프레임 규칙 때문에 실제 영상 길이는 약간 달라질 수 있습니다.
해상도
자동 옵션은 원본 비율을 참고하고 모델 단위에 맞춰 크기를 조정합니다. 높은 해상도는 더 느리고 메모리를 많이 사용합니다.
동작 여백
없음·10%·20%·30%. 기본 10%는 입력을 90% 크기로 줄여 중앙 배치합니다. 양쪽에 약 5%씩 여유가 생기며 출력 해상도는 그대로입니다. 캐릭터 픽셀 크기는 줄고, 이미 잘린 부분을 복구하지는 못합니다.

대상 유형 · 동작

인간형
호흡·체중 이동·머리카락과 옷자락 등 사람 중심 템플릿입니다.
생물 / 괴물
원본에 있는 몸과 부속 기관으로 움직이도록 지시합니다.
부유 기계
부유와 기존 기계 관절 움직임을 사용하고 장갑판·총열의 단단한 구조를 유지하도록 지시합니다.
지상 기계
기존 바퀴·궤도·지지 관절과 지면 접촉을 기준으로 움직입니다.
애니메이션 종류
Idle은 지속 대기, Walk/Run은 제자리 이동, Attack은 공격, Cast는 스킬, Hit는 피격, Death는 사망, Jump는 점프, Custom은 직접 설명입니다. 유형에 따라 같은 동작의 설명도 달라집니다.

유형 변경은 동작 설명을 교체합니다. 직접 작성한 설명이 있으면 교체 확인창이 표시됩니다. 원본에 없는 기관·부품을 요구하지 않도록 설명을 확인하세요.

프롬프트와 세팅 모음

세팅 모음
선택 후 ‘불러오기’를 눌러 적용합니다. ‘사용 안 함’을 불러오면 현재 유형·동작의 기본 설명으로 돌아가고 다른 옵션은 유지합니다.
조준 대기
인간형·Idle·약함·원본 방향·깜박임 없음·루프 켜짐을 적용합니다. 작은 체중 이동과 호흡을 팔이 보상해 조준선을 유지하도록 지시합니다. 길이·해상도·생성 모드는 바꾸지 않습니다.
움직임 강도
약함·보통·강함. 기본은 보통입니다. 프롬프트의 동작 크기를 조절하며, 강할수록 형태 변형이나 잘림 위험이 있습니다. 스텝 수는 바뀌지 않습니다.
방향 고정 / 눈 깜박임
원본 방향 또는 지정 방향을 유지하도록 지시합니다. 눈은 없음 또는 최대 한 번이며 기계에는 적용하지 않습니다. 정확한 방향·횟수를 보장하지는 않습니다.
동작 설명 / 템플릿 불러오기
움직일 부위와 유지할 부위를 구체적으로 적으세요. 불러오기는 설명을 기본 템플릿으로 교체합니다. ‘모든 부위 고정’과 ‘크게 움직임’처럼 상충하는 지시는 피하세요.

루프 · 정규화 · 실험 옵션

루프
시작·끝에 같은 참조 이미지를 사용해 연결을 유도합니다. 완벽한 연결을 보장하지 않습니다. 죽음처럼 마지막 자세가 달라야 하는 동작은 꺼두세요.
크기·프레이밍 정규화
영상 생성 후 캐릭터 배치를 보정합니다. 분석이 부정확하면 결과가 어색할 수 있으니 H3 원본과 비교하세요. 동작 여백 사용 시 추가 확대는 제한됩니다.
CFG 네거티브 — 기본 꺼짐
억제할 내용을 별도 입력하는 실험 기능입니다. 추가 계산·메모리 부담이 있고 형태나 색이 손상될 수 있습니다. 강도 범위는 1.1~2.0입니다.
Seed
비우면 무작위입니다. 설정을 비교할 때 같은 값을 쓰면 비교에 도움이 되지만 완전히 동일한 결과를 보장하지는 않습니다.

시트 · 누끼 · 재추출

시트 프레임
2~64장, 기본 8장. 생성 영상에서 고르게 골라 최대 8열로 배치합니다. 프레임 수를 늘려도 영상 생성 스텝은 늘지 않지만 시트 크기와 메모리 사용량은 커집니다.
단색 배경 누끼 — 기본 꺼짐
가장자리와 연결된 비슷한 배경색을 제거해 별도 투명 PNG 시트를 만듭니다. 강도는 4~64입니다. 의상·머리카락이 손상되거나 닫힌 공간의 배경이 남을 수 있습니다. 원본 시트·영상은 보존하며 영상 자체는 투명해지지 않습니다.
갤러리 → 시트 다시 추출
기존 생성 영상에서 2~64프레임을 다시 뽑습니다. AI 생성 없이 원본 시트를 보존하고 별도 다운로드 링크를 추가합니다. 누끼는 적용하지 않습니다. 본인 결과 또는 관리자만 실행할 수 있습니다.

팀 대기열 · 갤러리 · 계정

생성은 등록 순서대로 한 번에 하나씩 처리합니다. 개인 최대 3개, 전체 최대 20개까지 대기 작업을 등록할 수 있습니다. 대기열에서 작업자와 원본 이미지를 확인하며 대기 중인 본인 작업은 취소할 수 있습니다.

완료 영상과 시트는 로그인 전 공개 갤러리에서도 볼 수 있습니다. 민감한 결과는 업로드·생성 전에 공개 범위를 고려하세요. 생성과 재추출은 승인 계정이 필요합니다.

갤러리의 ‘결과 삭제’는 본인 또는 관리자만 가능합니다. 공개 갤러리와 다운로드에서 빠지지만 복구용 파일과 기록은 서버에 보관되므로 디스크 영구 삭제는 아닙니다.

관리자는 ‘계정 승인’에서 가입 요청을 승인하거나 이용을 제한할 수 있습니다.

결과가 이상할 때

  • 잘림: 동작 여백을 늘리거나 움직임 강도를 낮추세요. 원본 이미지부터 잘린 부분은 복구되지 않습니다.
  • 몸 전체가 들썩임: 움직일 부위를 좁히고 조준 대기 같은 세팅을 활용하세요.
  • 배경 생성: 단색 배경 지시도 완벽하지 않습니다. 원본 입력과 다른 설정으로 비교하세요.
  • 오래 걸림: 일반 20스텝·고해상도·긴 영상은 느립니다. 팀 대기열에서 상태를 먼저 확인하세요.
  • 옵션 변경: 이미 등록한 작업에는 소급 적용되지 않습니다. 설정을 바꾼 뒤 새 작업을 등록하세요.
