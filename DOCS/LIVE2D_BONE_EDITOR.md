# 웹 본 편집·포즈 테스트 · 인계

## 사용하는 곳

레이어를 고치며 기존 자동 움직임을 확인하려면 상단 **Live2D 미리보기**를 켜세요. 저장 전 픽셀과 표시·순서 변경도 반영합니다. 본·IK·타임라인은 아래 **포즈 테스트**에서 확인합니다. [레이어 편집 중 미리보기](LIVE2D_LIVE_PREVIEW.md).

결과 갤러리 또는 **내부 공유 링크 → 레이어 편집기** 상단에서 모드를 고릅니다.

- **레이어 편집**: 기존 브러시·지우개·표정 차분을 사용합니다.
- **본 위치·연결**: 점을 드래그하거나 우측 좌표를 입력해 원래 관절 위치와 부모 본을 수정합니다. 원본 픽셀은 움직이지 않습니다. 본 이름은 켜고 끌 수 있고, 메시 보기로 파츠의 격자를 확인합니다.
- **포즈 테스트**: 점을 드래그하거나 우측 회전 슬라이더를 움직입니다. 파츠 메시와 자식 본이 함께 움직입니다. **포즈 취소/다시 실행**, **포즈 초기화**를 지원합니다. 키프레임으로 기록하지 않은 포즈는 임시 테스트이며, 기록한 클립은 따로 저장합니다. PSD·Unity 원래 자세를 바꾸지 않습니다.

레이어·표정 편집은 먼저 저장한 뒤 본 모드로 전환하세요. 본 수정은 상단 **PSD와 패키지에 저장**으로 새 작업 버전에 기록합니다. Ctrl+Z/Y는 본 위치 편집에서는 작업 기록, 포즈 테스트에서는 임시 포즈를 되돌립니다.

## 머리카락·코트·토시를 만지는 방법

1. **본 위치·연결**에서 우측 레이어 목록의 해당 파츠를 선택합니다.
2. **선택 파츠에 유연 조작점 추가**를 누르면 뿌리와 끝 조작점이 생기고 그 파츠가 연결됩니다. 머리카락은 기본 조작점도 자동 제공됩니다.
3. 뿌리·끝을 실제 이미지에 맞춰 옮깁니다. 우측 **따를 본** 체크 목록으로 영향을 주는 본을 조정합니다. 최소 1개, 최대 16개이며 실제 각 메시 정점은 가까운 본 2개를 따릅니다.
4. **포즈 테스트**로 전환해 끝을 드래그하거나 뿌리를 회전합니다.
5. 테스트 후 본 설정을 저장하고 **저장본으로 Unity V2 생성**을 누릅니다.

잘못 추가한 조작점은 **선택 조작점 삭제**로 자식과 함께 삭제합니다. 기본 전신 본은 삭제할 수 없습니다. 본은 전체 96개까지 지원합니다. 표정 파츠는 머리 본에 고정합니다.

손·발 2본 IK와 타임라인·키프레임·모션 저장이 추가되었습니다. [IK·타임라인 가이드](LIVE2D_TIMELINE.md)를 참고하세요. 키로 기록하지 않은 포즈는 임시 테스트이며, 기록한 클립은 저장·V2 내보내기를 지원합니다. 큰 움직임은 가려졌던 부분이나 파츠 경계가 드러날 수 있어 그림·레이어 보정이 필요합니다.

## 저장과 공유·Unity

- `manifest.rigEditor`에 원래 자세의 본·부모 연결·파츠 바인딩을 보관합니다. 편집 작업 `rig_config`를 기존 revision 저장 API로 보내므로 원본·과거 버전이 유지됩니다.
- PSD와 합성 PNG는 원래 픽셀을 유지합니다. 본 편집 기록은 manifest/ZIP에 포함되며 PSD 자체에는 본 정보가 저장되지 않습니다.
- V2의 `rig-v2.json`에는 편집한 본과 `layerMeshes` 정점·인덱스·본 웨이트가 들어갑니다. 웹과 Unity는 같은 9×9 격자와 가까운 본 최대 2개 웨이트 규칙을 사용합니다.
- V2 importer는 `layerMeshes`가 있으면 그대로 사용합니다. 이전 ZIP에는 기존 자동 메시·웨이트 계산을 사용합니다. 얼굴 차분은 머리 본을 따릅니다.
- 내부 공유에서도 편집·저장·V2 생성 및 ZIP 다운로드가 가능합니다. 공개 워크스페이스의 기존 게시본은 자동으로 변경하지 않습니다.
- 확대본 적용/다운로드는 저장된 본의 픽셀 좌표와 길이도 확대합니다. 본을 고친 뒤 레이어를 복원·병합한 경우 파츠 바인딩을 다시 확인하세요. 삭제된 파츠의 바인딩은 제거되고 새 파츠는 기본 연결이 채워집니다.

## 구현·검증

- `rigging_bones.py`: 본 검증, 기본 본·머리카락 조작점, 파츠 연결, 공유 메시·웨이트 생성.
- `rigging_editor.py`: `rig_config` revision 저장·복원과 파츠 변경 후 연결 정리.
- `web/rigging-bones.js`: 모드·관절 조작·2D 스키닝 미리보기·포즈 임시 기록.
- `team_server.py`: 편집 payload의 `rig`, `/rigging-bones.js`, 내부 공유 `/share/rig/<token>/rig-v2`.
- `rigging_v2.py` 및 V2 importer: 편집된 본·메시 내보내기와 가져오기.

`test_rigging_bones.py`는 본 순환·좌표·바인딩 검증과 revision/복원/V2/확대를 확인합니다. `tools/test_rigging_bones.cjs`는 Chrome의 드래그·실제 픽셀 변형·조작점·포즈 취소·회전·저장·내부 공유를 검증하고 Python과 JS의 웨이트가 같은지도 비교합니다. 실제 Unity Editor 임포트 검증 여부는 작업 결과에 별도로 기록합니다.

2026-10-13: 브라우저·Python·공유 API 검증 및 Unity 6000.3 참조/기존 2D Animation 참조를 사용한 Roslyn C# 컴파일에 성공했습니다. 실제 Unity Editor의 프리팹 임포트·재생은 이번 작업에서 실행하지 않았습니다. `editorSkinningVersion=1`이 없는 이전 V2 ZIP은 새 V2 생성 시 재생성하여 공유 메시·웨이트를 포함합니다.
