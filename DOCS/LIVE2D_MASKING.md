# Live2D 생성 전 눈·입 마스킹 도구

2026-10-18. 리깅 전 마스킹 화면에 레이어 편집기와 공통 조작을 제공한다. 영역 칠하기/감은 눈 직접 그리기 및 기존 생성 API는 유지한다.

## 조작

- **B** 브러시, **E** 지우개, **H** 화면 이동. 브러시/지우개 전환 시 선택 영역과 브러시 크기를 유지한다.
- **1/2** 화면 왼쪽/오른쪽 눈, **3/4** 눈썹, **5** 입. 눈썹 보존 옵션을 끄면 해당 단축키도 비활성.
- **[ / ]** 브러시 크기 조절(2~256px), 펜 필압 반영. 캔버스에 브러시 크기 원 표시.
- **Space+드래그**, 휠 버튼 드래그로 화면 이동. H는 지속 이동 도구. 이동 중 마스크를 그리지 않는다.
- **Ctrl/Cmd+휠** 포인터 위치를 기준으로 확대. **Ctrl+/−**, **Ctrl+0** 화면 맞춤, **Ctrl+1** 원본 100%. 확대 10~800%, 가로·세로 동일 배율.
- **Ctrl+Z** 실행 취소, **Ctrl+Shift+Z / Ctrl+Y** 다시 실행. 선택 영역 지우기/전체 지우기도 취소 가능. 이미지가 바뀌면 기록 초기화. 최대50개 편집 이력.
- **Q** 마스크 표시/숨김. 투명도10~80% 조절은 화면에만 적용하며 생성용 PNG 마스크 값은 유지한다. 직접 그린 감은 눈의 어두운 미리보기는 별도 옵션.
- 상단에 현재 영역/브러시·지우개·이동 상태/브러시 크기를 표시. 입력칸·선택 필드·편집 텍스트에서는 단축키를 가로채지 않는다. 버튼의 Space 활성화도 보존한다.

## 마스크 의미와 구현

`web/assets/rigging-mask-tools.js`/`.css`가 기존 `web/rigging.html`의 도구·이벤트·렌더링을 확장한다. 전역 setTool/setupCanvas/renderMasks를 감싸 기존 이미지 업로드/재생성 연계를 유지한다.

새 지우개 획에는 `target`을 넣어 현재 영역만 지운다. export용 maskCanvasFor도 target을 확인한다. target 없는 기존 지우개 획은 기존 전역 지우기 의미 유지. 눈 영역/감은 선 모드의 획과 지우개는 모드별로 구분한다. 렌더는 영역별 scratch canvas를 재사용해 지우개가 다른 영역 표시를 지우지 않게 한다.

이력은 완성된 획 전후의 배열 스냅샷(획은 완료 후 불변)이며 clear도 같은 이력에 포함. pointercancel/창 포커스 상실 시 진행 중 획은 취소하고, pointer capture/이동 상태를 해제한다. 색/투명도/커서는 생성 이미지에 합성하지 않는다.
