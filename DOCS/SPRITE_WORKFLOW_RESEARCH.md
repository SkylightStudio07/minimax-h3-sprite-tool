후속 구현: H3 프로젝트의 실제 native 그래프는 README 기본 목록과 달리 FastH3 8-step 전용 모델을 사용한다. 이를 확인하고 별도 선택 프로필을 추가했다. [FASTH3_SPRITE_WORKFLOW.md](FASTH3_SPRITE_WORKFLOW.md)에 다운로드·검증 대기 상태와 적용 범위를 기록했다.

2026-10-15. 사용자가 언급한 프로젝트 이름은 불명확하므로 아래는 후보이며 동일 프로젝트라고 단정하지 않는다. 외부 코드는 설치·실행하지 않았다.

## MiniMax H3 기반 — 우선 참고할 후보

출처: https://github.com/xiaojiangxj33/h3-sprite-generator

작성자 README 확인: ComfyUI용 웹 프론트로 참조 이미지 → H3 영상 → 프레임 선택 → 배경 제거 → 크롭 → PNG ZIP/Eagle 내보내기를 제공한다. 코드 MIT 표기. 원본 H3 워크플로우와 T8 노드 워크플로우 선택이 있으며, README에 나열된 H3 diffusion/CLIP/VAE 파일명이 우리 idle_tool.py 구성과 같다. 다만 노드 스키마·버전·별도 의존성은 대조 및 실행 검증 전이므로 바로 호환된다고 확언하지 않는다.

우리 도구에 참고할 가치가 높은 것은 실시간 배경 제거(경계 feather/despill/alpha gamma 등), 프레임 제외·복원 및 연속 선택, 전체 프레임에 같은 크롭을 적용하는 흐름이다. 작성자가 게임 특수효과를 강조하므로 캐릭터 애니메이션 품질 개선까지 보장하는 자료는 아니다. 현재 서비스 전체를 교체할 필요는 없고 프레임 후처리부터 비교하는 것이 적절하다.

## IP-Adapter + LoRA + ControlNet 기반 — 정지 에셋 일관성 후보

출처: https://github.com/wy715464489/comfyui_workflow

작성자 README 확인: 캐릭터/배경/UI 에셋을 일관된 스타일로 배치 생성하는 구성. SD1.5 계열(MeinaMix 등), Animagine XL 3.1/SDXL 및 IP-Adapter, 선택적 ControlNet을 설명한다. 우리 Anima Turbo에 그대로 붙이는 구성은 아니다. Animagine 쪽에 별도 호환 모델과 노드를 맞춰 참조 이미지 일관성/포즈 제어를 실험하는 방향으로 참고할 수 있다. 원본 문서의 손 품질/속도 평가를 우리 환경의 검증 결과로 인용하지 않는다.

## 판단

화풍 다양화에는 검증된 애니메이션/셀 채색/선화 전용 LoRA를 추가하는 것이 유효하다. 캐릭터 일관성·포즈·동작은 스타일 LoRA만 늘려서는 해결되지 않으므로 참조 조건 및 포즈 제어와 별도로 다룬다. 신규 모델 다운로드나 외부 노드 설치는 이번 조사에서 하지 않았다.
