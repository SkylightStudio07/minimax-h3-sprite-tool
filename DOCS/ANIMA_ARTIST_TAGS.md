# Anima 작가 태그 검증 — 2026-10-17

## 혼합 화풍 후속

사용자 요청으로 기본 노출을 혼합 조합 3종으로 변경: 차가운 전술 채색(nardack+ask), 담백한 셀 채색(ciloranko+jima), 색선·종이 질감(fkey+nardack). 각각 선/명암/색/질감 지시를 추가했다. `tools/verify_artist_mixes.py`, `outputs/artist-mixes-20261017/comparison.jpg`: 동일한 두 인물/인물별 seed로 6장 확인. 여러 seed에 대한 안정성은 아직 검증하지 않았다. 혼합이 법적 면책이나 독창성을 보장한다는 뜻은 아니다.

기존 4종은 artist-study 계열의 실험·비교용으로 이동하고 전체 기본 목록에서는 제외한다. 실제 태그는 카드 상세/생성 메타데이터로 유지. 혼합은 피부 창백함·소품 변동·배경 질감 발생이 남아 있어 카드에 표시한다.

라이브러리는 우측 독립 스크롤 패널, 생성/결과는 좌측 작업 패널로 변경. 작은 화면에서는 열기/닫기 버튼으로 우측 패널을 표시. 카드 적용 시 강제 scrollIntoView 제거. 브라우저에서 우측 배치/뷰포트 높이/독립 스크롤/반응형 열/생성 요청 검증.

사용자가 일반적인 AI 그림 느낌을 줄이기 위해 커뮤니티의 작가 태그/혼합을 조사하고 실제 프리셋으로 반영하도록 요청했다.

## 조사 근거

- 공식: https://huggingface.co/circlestone-labs/Anima/blob/main/README.md — 작가 앞 `@` 필수, 없으면 효과가 약하다고 명시. 태그와 자연어 혼용 지원. 기본 그림체가 의도적으로 중립적이므로 작가/품질 태그 없이 밋밋할 수 있다고 설명.
- 중국어 가이드: https://github.com/Moeblack/ComfyUI-AnimaTool/blob/main/wiki/Prompt-Guide.md — fkey+jima, ciloranko, nardack, ask 후보. 작가명 괄호는 Comfy 파서에 맞게 이스케이프. 가이드에 있는 단일 줄/가중치 관련 주장을 모든 모델의 법칙으로 간주하지 않음.
- 추가 발견: https://anima.mooshieblob.com/ 작가 탐색기. 외부 예시를 우리 생성 결과처럼 사용하지 않음.
- AI 그림 채널/공식 Civitai 게시글은 검색만으로 직접 검증 가능한 원문 확보가 제한돼 해당 커뮤니티의 합의라고 주장하지 않음. 미러 사이트의 가중치 혼합 특수 문법은 현재 인코더와 검증되지 않아 도입하지 않음.

## 실험

`tools/verify_artist_tags.py`: 태그 없음 / @fkey, @jima / @ciloranko / @nardack / @ask \(askzy\). 은발 전술요원과 남성 검사 두 인물, 인물별 동일 seed, Anima Turbo, 768×1024, LoRA 없이 태그만 변경. 총 10장. 저장: `outputs/artist-tags-20261017/`.

태그가 특정 작가의 실제 작업이나 참여를 의미하지 않으며, 예시는 서버에서 생성한 것이다. Turbo에서 관측한 결과를 Base/Aesthetic 품질로 일반화하지 않는다. 혼합 태그에 숫자 가중치를 임의로 붙이지 않는다.

## 운영 반영

10장 완료. nardack/ask에서 선·명암 차이가 확인됐고, ciloranko는 은발이 갈색으로, fkey+jima는 무전기가 총으로 변한 사례가 있었다. 개선을 일률적으로 보장하지 않고 카드 주의점에 표시한다. 4종을 실험적으로 등록하여 공개 프리셋 30→34종. 프리셋 탭은 artist 그룹을 기본 표시한다. 각 카드에 두 인물 예시가 있고 실제 태그를 펼쳐 볼 수 있다.

브라우저 테스트: 작가 프리셋 선택 시 LoRA 해제/캐릭터 설명 보존, 기존 프리셋 전환/요청/반응형 검증. 백엔드는 기존 lookId 경로를 재사용하므로 서버 재시작 없이 JSON/정적 파일 새로고침으로 반영된다.

`web/assets/image-looks.json`의 artist 그룹으로 관리한다. 사용자가 프리셋을 선택할 때만 적용하고 원본 캐릭터 설명은 유지한다. 기존 lookId 기반 서버 조립/메타데이터 기록을 재사용하며 프리셋 전환 시 태그를 누적하지 않는다. LoRA 없는 프리셋을 선택하면 기존 LoRA 선택을 해제한다. 카드에 실제 태그와 두 인물 예시를 노출한다.
