## 구성

6계열 × 6종: 플랫 컬러(종이 오리기/파스텔/원색/벡터/셀/제한 팔레트), 선화(얇은 선/굵은 외곽선/연필/해칭/컬러 라인/붓펜), 애니메이션(현대/레트로/부드러운 채색/키 비주얼/무광/강한 명암), 회화(과슈/수채/유화/디지털/각진 색면/동화책), 흑백·인쇄(만화/해칭/목탄/두 색/목판/리소), 게임(SD/전술/판타지/스티커/픽셀/카툰).

기존 3개 검증 LoRA와 Anima Turbo/Animagine XL을 조합했다. 새 LoRA 36개를 받은 것이 아니다. LoRA 강도 0.25~0.85와 양성/음성 프롬프트를 개별 구성했다. 증류 모델 Anima Turbo는 검증된 10 steps / CFG 1을 유지하며 임의로 CFG를 높이지 않는다. Animagine은 28 steps / CFG 5다. 적용 후 사용자가 수치를 수정할 수 있다. 프리셋마다 모든 수치가 서로 달라야 하는 것은 아니다.

각 프리셋의 모델·LoRA·강도·steps·CFG와 실제 생성 예시를 카드에 표시한다. 계열 필터와 이름/영문 프롬프트 검색, 적용 프롬프트 펼치기를 제공한다. 선택한 모델이나 LoRA가 준비되지 않았으면 적용 버튼을 막는다.

## 적용과 재현

- `web/assets/image-looks.json`: version 1, 36개 allowlist, 추천 설정, 스타일 지시, 제외 지시, 시각 확인 메모, 자체 생성 예시 경로.
- `web/assets/image-looks.js`: 클릭하면 모델/LoRA/강도/steps/CFG만 변경한다. 캐릭터 설명·용도·해상도·시드·배경 설정은 유지한다.
- `image_looks.py`: 모델 일치 및 ID 검증 후 resolvedPrompt/resolvedNegativePrompt에 한 번만 결합. 숫자 설정은 사용자가 변경한 값을 유지한다. API 사용 시 추천 설정을 함께 전달해야 하며 lookId만으로 추천 모델/수치를 강제로 덮어쓰지 않는다.
- `image_engine.py`: lookId/이름/version/양성·음성 지시와 최종 프롬프트를 작업 및 PNG 메타데이터에 저장한다. 기존 LoRA 트리거와 충돌하지 않게 flat-color 조합 대부분은 `flat color`만 사용한다. paper/vector만 `no lineart`를 추가한다. 사용자가 다른 LoRA로 바꾸면 해당 LoRA의 기본 트리거를 사용한다.
- 프리셋 변경은 이전 스타일 지시를 교체하므로 캐릭터 텍스트에 누적되지 않는다. 모델을 수동 변경하여 호환되지 않으면 적용 프리셋을 해제한다. 다시 생성하기는 프리셋 ID 및 수동 조정 수치를 복원한다.
- ‘그림체 지시 해제’는 스타일 프롬프트만 제거한다. 모델·LoRA·수치는 유지함을 UI에서 명시한다. 기존 템플릿으로 캐릭터 설명에 직접 추가한 문구는 별개이므로 사용자가 제거한다.

## 검증 및 관찰

`tools/verify_image_looks.py`로 동일 캐릭터 설명·시드 20261015·832×1216 조건에서 36종 모두 생성 성공. Anima 약 6~8초, Animagine 약 13~15초. 운영 계정이나 갤러리에 테스트 항목을 넣지 않는다. 팀/Comfy 큐가 비어 있을 때 수동 실행하며 이미 같은 설정으로 생성한 사례는 재사용한다.

원본·설정·prompt ID·실행 시간·6계열 비교표: `outputs/look-validation-20261015/`. 자체 생성 예시 36개: `web/assets/image-look-previews/*.webp` (총 약 5MB). 기존 image-styles의 제작자 예시와 구분하여 표시한다.

모든 비교표를 육안 확인했다. 플랫 채색, 굵기 다른 선화, 레트로 애니, SD/픽셀/전술에서 변화가 보인다. 다만 다음을 성공한 특성으로 과장하지 말 것:

- paper/vector는 종이 질감이나 완전한 무선화보다 형태 단순화 효과가 강하다. 벡터 파일이 아니다.
- painterly 일부는 반실사 얼굴로 기울고 watercolor도 각진 채색이 강해질 수 있다.
- smooth-lines 기반 조합은 밝은 얼굴 지시에도 얼굴이 어둡게 나올 수 있다.
- 흑백·두 색 지시보다 캐릭터의 색상 지시가 우선되어 유채색이 남기도 한다.
- 픽셀아트풍은 일정한 격자/게임용 해상도를 보장하지 않는다.
- 한 캐릭터·시드의 예시이므로 모든 구도/캐릭터에 같은 효과를 보장하지 않는다. 현재 카탈로그에 실험적 표시 및 개별 메모를 유지한다.

테스트: `python -m unittest test_image_engine`, `node tools/test_image_studio.cjs`. 36개 ID 유일성, 모델 불일치·미등록 ID 차단, 스타일 문구 중복 방지, 트리거 충돌 제거, 숫자 수동 수정 유지, 필터/검색/미설치 차단/실제 제출 항목, 기존 생성·마스킹·전달·반응형 확인.

배포 완료: 팀 대기열이 비어 있을 때 HTTPS 설정으로 서버 재시작. 외부 사이트의 프리셋 JSON 36개·UI 스크립트·자체 예시 WebP가 HTTP 200임을 확인했다. 백엔드 테스트 6건 및 브라우저 통합 테스트 통과.

새 프리셋을 추가하면 카탈로그와 UI 개수 표기, 테스트 개수, 실생성 예시 및 메모를 함께 갱신한다. 예시를 모델 변경 후에도 재활용하지 말고 검증 설정과 일치시킨다.
