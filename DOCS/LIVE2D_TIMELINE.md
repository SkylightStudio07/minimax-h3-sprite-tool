# IK·타임라인 · 사용법과 유지보수

## 작업 순서

레이어 편집기를 열고 **포즈 테스트**를 선택하면 캔버스 아래 타임라인이 나타납니다.

1. 본 위치·연결이 캐릭터와 맞는지 먼저 확인합니다. 팔은 `어깨 → 팔꿈치 → 손목`, 다리는 `허벅지 → 무릎 → 발목` 연결이 필요합니다.
2. **손·발 IK**를 켜고 손목·발목 점을 드래그합니다. 두 구간 길이를 유지하면서 팔꿈치·무릎이 접힙니다. **굽힘 반전**으로 반대 방향을 선택할 수 있습니다. 목표가 너무 멀거나 가까우면 도달 가능한 범위로 제한됩니다. IK를 끄거나 Alt를 누른 채 드래그하면 기존 자유 이동입니다.
3. 0프레임에서 시작 자세를 만들고 **◆ 키 추가·갱신**을 누릅니다.
4. 프레임 슬라이더를 옮겨 다음 자세를 만들고 다시 키를 추가합니다. **자동 키**를 켜면 드래그·회전·굽힘 반전을 끝낼 때 현재 프레임이 기록됩니다.
5. **재생/일시정지**, **처음**, 프레임 슬라이더로 동작을 확인합니다. 이름, FPS, 길이, 반복, 보간을 바꿀 때 **클립 설정 적용**을 누릅니다.
6. **PSD와 패키지에 저장**으로 새 작업 버전에 클립을 기록합니다. 수정 후 **저장본으로 Unity V2 생성**을 누릅니다.

보간은 **부드럽게 / 선형 / 유지** 중 선택합니다. 반복은 마지막 키에서 첫 키까지 이어집니다. 회전은 가장 짧은 방향으로 보간하므로 179°에서 −179°로 바뀔 때 한 바퀴 돌지 않습니다. 한 바퀴 회전은 중간 키들을 추가해 방향을 지정하세요.

## 키·클립 편집

- **복사 → 다른 프레임 → 붙여넣기**로 자세를 복제합니다.
- 키를 선택하고 **키 이동**의 프레임 번호를 입력하면 그 위치로 옮깁니다. 이미 키가 있는 프레임으로 이동할 수 없습니다.
- **키 삭제**, **키 편집 취소/다시 실행**, Ctrl+Z/Y를 지원합니다. 포즈 취소는 기록 전 임시 자세, 키 편집 취소는 저장 대상 클립을 되돌립니다.
- **클립 추가/삭제**로 Idle, 손 흔들기 등을 따로 관리합니다.
- 키는 현재 **전체 본 자세의 스냅샷**입니다. 본별 행의 ◆는 기록된 변형, ◇는 기본 자세를 뜻합니다. 행의 키를 클릭하면 해당 프레임과 본을 선택합니다. 본별로 독립된 시간에 키를 배치하는 트랙 편집은 아직 제공하지 않습니다.
- 최대 클립 16개, 클립당 키 512개, 전체 키 2048개, FPS 1~60, 길이 2~3600프레임입니다. 길이를 줄일 때 범위 밖 키를 먼저 이동·삭제해야 합니다.

단순히 포즈를 움직인 상태는 임시 작업입니다. **키 추가/자동 키로 기록한 동작**이 저장됩니다. PSD·합성 PNG의 원본 픽셀은 바뀌지 않습니다. 원래 자세의 본 설정과 동작 클립은 별도로 보관합니다. 이전 버전 복원도 지원합니다.

## Unity

V2 ZIP의 `rig-v2.json.animations`에는 로컬 본 이동·회전 트랙이 포함됩니다. 임포터는 FPS별로 보간을 계산하여 `Animations/*.anim`을 만들고 프리팹에 `RiggingV2ClipPlayer`를 추가합니다. 빈 클립은 재생 동작을 생성하지 않습니다.

**임포터 0.4.0 이상이 필요합니다.** 기존 원클릭 임포터를 설치했다면 사이트에서 최신 ZIP을 받아 패키지 폴더를 업데이트하세요. ZIP의 Unity 소스를 직접 사용하는 경우 새 Editor/Runtime 파일도 함께 복사합니다.

```csharp
using SpriteLab.RiggingV2;
var player = avatar.GetComponent<RiggingV2ClipPlayer>();
player.Play("손 흔들기"); // 이름 또는 clip_* ID
player.Stop(); // 원래 자세와 기존 idle 컨트롤 복구
```

클립 재생 중 기존 몸·머리카락·옷 idle은 잠시 멈춰 본 애니메이션을 덮어쓰지 않게 하며, 기존 눈 깜박임·자동 입 움직임은 유지합니다. 웹에서 IK를 풀어 기록한 본 변형을 재생하는 방식이며, Unity에서 실시간 IK 목표를 조작하는 시스템을 추가하는 것은 아닙니다. 기존 갤러리의 PSD 플레이어는 기존 idle을 사용합니다. 기록한 클립은 편집기와 Unity에서 재생합니다. 공개본은 관리자 갱신 정책을 유지합니다.

## 인계

- `web/rigging-animation-math.js`: 2본 IK·키 보간의 순수 함수. Node에서 검증 가능.
- `web/rigging-animation.js`: IK 조작, 전체 포즈 키, 재생·반복·클립·취소 기록.
- `rigging_animation.py`: 저장 형식 검증, 삭제 본 정리, 보간, Unity 트랙 변환.
- `rigging_editor.py`: `rig_animation` revision 작업. 함께 전달한 원래 본 설정도 보관해 기존 V2의 수동 관절 위치를 유지합니다.
- `rigging_v2.py`: `editorSkinningVersion=2`, 애니메이션 트랙 내보내기.
- `RiggingV2AnimationBuilder.cs` / `RiggingV2ClipPlayer.cs`: `.anim` 생성·재생. 원클릭 배포 ZIP에도 포함.
- `rigging_upscale.py`: 본 이동 dx/dy 확대, 회전 각도·프레임·FPS 유지.

검증은 `test_rigging_animation.py`, 공유 저장 API 테스트, `tools/test_rigging_animation_math.cjs`, `tools/test_rigging_timeline.cjs`를 사용합니다. 모델 생성이나 운영 결과 편집 없이 실행됩니다. C# 컴파일 검증과 실제 Unity Editor 임포트·재생 검증은 구분합니다.
