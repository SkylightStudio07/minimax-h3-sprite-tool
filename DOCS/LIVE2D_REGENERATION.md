# Live2D 눈·입·장비 재생성

## 사용법

결과 갤러리 → 레이어 편집 또는 내부 공유 링크 → 레이어 편집에서 우측 **눈·입·장비 다시 생성**을 사용합니다.

1. 현재 수정 사항을 저장하거나 취소합니다.
2. 감긴 눈, 입 열림/닫힘, object 장비 중 원하는 슬롯을 고릅니다. 패키지에 좌우 눈 슬롯이 따로 있으면 각각 선택할 수 있습니다. 한 슬롯에 두 눈이 있으면 함께 생성합니다.
3. 눈·입은 추가 요청을 입력할 수 있습니다. 예: `가늘고 자연스러운 감긴 눈`.
4. **선택 파츠 다시 생성**을 누릅니다. 다른 생성과 같은 대기열에서 처리됩니다.
5. 원본 참고 / 현재 레이어 / 새 후보를 비교합니다. 닫으면 기존 결과를 유지합니다.
6. **이 파츠에 적용** 후 **PSD와 패키지에 저장**합니다. 저장 전 Ctrl+Z로 취소할 수 있고, 저장 후에도 이전 버전 복원이 가능합니다.

갤러리와 내부 공유는 저장한 새 버전을 사용합니다. 기존 Unity V2 다운로드는 무효화되므로 다시 생성해야 합니다. 공개 워크스페이스 복제본은 관리자가 다시 공개해야 갱신됩니다.

## 처리 방식과 한계

- 기존 감긴 눈·입은 선 추정과 변형을 사용합니다. 이번 기능은 Qwen Image 2.1 편집 경로로 원본 얼굴 주변을 참고해 새 후보를 만듭니다. 모델이 설치되어 있어야 합니다.
- 눈·입은 작은 피부 패치와 함께 생성합니다. 경계는 부드럽게 처리하지만 피부색, 앞머리, 눈썹이 일부 포함되거나 얼굴 각도가 달라질 수 있습니다. 확대 비교 후 적용하고 필요하면 지우개로 정리합니다. 원본과 일치하거나 매번 개선된다는 보장은 없습니다.
- object는 See-through로 원본 전체를 다시 분리하고 선택 슬롯 주변의 object 픽셀만 가져옵니다. 다른 레이어는 교체하지 않습니다. 주변에 장비가 여러 개 있거나 원본에 가려진 부분은 정확히 분리되지 않을 수 있습니다. 추가 요청 입력은 object에서 사용하지 않습니다.
- 처음 업로드한 원본이 없는 이전 작업은 **기존 작업에 원본 연결**이 필요합니다. 현재 저장 상태와 원본의 해상도가 달라도 캔버스 좌표에 맞춥니다.
- 재생성은 생성 후보만 만들며 원본 패키지를 변경하지 않습니다. 후보 생성 후 다른 편집을 했다면 저장/취소 후 다시 생성하세요.

## 유지보수

- `rigging_regenerate.py`: 대상 검증, Qwen 얼굴 문맥 크롭, See-through object 추출, 후보 저장. 난수 seed를 후보 메타데이터에 기록합니다.
- `team_server.py`: 작업/내부 공유의 `rig-edit/regenerate` POST 및 `rig-edit/regenerate/<task>` GET. `jobType=rig-part`로 FIFO 워커에서 실행합니다. 일반 갤러리에는 후보 작업을 노출하지 않습니다. 원본 소유자 또는 관리자, 유효한 내부 공유 링크만 접근할 수 있습니다. 공개 링크는 생성·후보 열람을 허용하지 않습니다.
- 후보는 `outputs/rig-candidates/<task>/candidate.png`, `candidate.json`에 보관되며 공개 정적 경로로 제공하지 않습니다. 서버 재시작 시 진행 중 작업은 기존 워커 정책에 따라 실패 처리됩니다. 완료 후보는 동일 API로 다시 읽을 수 있습니다.
- `web/assets/rigging-regenerate.js`: 대상 선택, 대기 상태, 비교창, 적용, 실행 취소/다시 실행. 페이지를 이동해도 서버 작업은 계속됩니다. 같은 탭으로 돌아오면 **이전 재생성 진행·후보 확인**으로 이어갈 수 있습니다. 탭 세션에 작업 ID만 보관하며 이미지 픽셀은 저장하지 않습니다.
- `rigging_editor.py`: `layer_png` 연산이 대상 슬롯 PNG와 좌표를 교체합니다. PNG/범위/빈 이미지 검증을 거치고 기존 revision 저장 흐름으로 PSD·ZIP·복구 버전을 갱신합니다.

검증: `python -m unittest test_rigging_regenerate test_rigging_expressions test_rigging_editor` 및 Playwright 환경에서 `node tools/test_rigging_regenerate.cjs`.
